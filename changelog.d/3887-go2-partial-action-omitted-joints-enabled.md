### Fixed: a Go2 action that names only some joints no longer disables the rest. `Go2Driver.send_action` with a partial action dict used to publish every joint it did not name with the Disable byte (`mode = 0`), the frame the driver itself documents as one that cuts those motors dead. The frame now starts with all twelve joints enabled at zero gain, the same soft-stop shape `build_zero_torque_lowcmd` publishes and the shape the Unitree SDK example writes on every frame; only the joints you name get targets and gains.
