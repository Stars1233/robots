### Fixed: `use_rtps` now refuses a `pkg/srv/Name` or `pkg/action/Name` interface type the way the RTPS docs promise, quoting the per-message DDS types ROS 2 generates for it (`..._Request_` and `..._Response_`, or `..._Goal_`, `..._Result_` and `..._Feedback_`). Before, the tool's own type check admitted service and action kinds, so such a call was answered with the cyclonedds install hint on a box without the extra, or with "not in the RTPS IDL bundle" on one with it, and never named the types you actually need. The refusal now comes from the same mangling that maps topics, so it reads the same with or without cyclonedds.
